# Third-party assets

## Kenney UI packs

`kenney-adventure/`, `kenney-ui/` and `kenney-borders/` are the
**UI Pack Adventure**, **UI Pack** and **Fantasy UI Borders** packs by
Kenney (<https://kenney.nl>).

Licence: **CC0 1.0 Universal** (public domain dedication). No attribution is
required; it is given here because the work deserves it and because a reader
of this repo should be able to tell at a glance which pixels are ours.

The game loads the `Vector/` (SVG) variants rather than the PNGs, so every
panel, button and bar stays crisp at any size and on any display density.
See `styles/kenney.css` for how each piece is sliced and applied.
